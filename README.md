# TradPlus Yandex Adapter Swift Package

Swift Package Manager support for the TradPlus Yandex adapter (15.17.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Yandex.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Yandex.git", exact: "15.17.0")
```

Third-party dependency: Yandex Mobile Ads SDK `8.5.0`. Minimum iOS 15.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.17.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
